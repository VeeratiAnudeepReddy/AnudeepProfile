GC Methane (demo) by Glyphonic. https://glyphonic.gumroad.com/l/gc-methane
Licence: the demo is free for PERSONAL USE only. Commercial and corporate use needs a purchased licence.
The demo contains only 56 glyphs: A-Z (without D), a-z and the full stop. There is no uppercase D, no digits and
almost no punctuation, so the site fills those in from Outfit (see app/globals.css and app/layout.tsx).
Buying the full font removes that limit: replace these files with the full GC Methane web fonts and delete the
unicode-range lines from the @font-face rules.
Files here are web (woff2) conversions of the Light, Regular, Medium, SemiBold, Bold and ExtraBold demo styles.
